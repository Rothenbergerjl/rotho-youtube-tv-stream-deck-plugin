# Security Policy

## Supported versions

Only the latest [release](https://github.com/Rothenbergerjl/rotho-youtube-tv-stream-deck-plugin/releases)
gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately from the repository's **Security** tab with
**Report a vulnerability** (GitHub private vulnerability reporting). Include what you found, how to
reproduce it, and which version you tested.

You'll get a reply when the report has been read. Fixes ship in a new release, and the report is
published as a security advisory once the fix is out.
